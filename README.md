# 2026 ICCAD Contest — Problem B

A regression failure bucketing tool for RISC-V hardware
verification, developed for the 2026 ICCAD Contest.

## Approach

- Feature extraction from regression, simulation, and trace logs
- TF-IDF vectorization and similarity-based clustering
- Performance evaluation using balanced accuracy and runtime

## Technologies

Python, NumPy, SciPy, scikit-learn
